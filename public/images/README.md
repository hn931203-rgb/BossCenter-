# 이미지 폴더

이곳에 사진을 넣으면 사이트에 자동 반영됩니다. (Next.js `public/` → 경로는 `/images/파일명`)

## Hero 배경 사진 (현재 연결됨)

- 파일명: **`hero-demolition.jpg`**
- 이 폴더에 `hero-demolition.jpg` 라는 이름으로 넣어주세요.
- 권장: 가로로 긴 고해상도 (예: 1920×1080 이상), 1~2MB 내외로 압축
- 다른 파일명을 쓰려면 `data/landing-demolition.ts`의 `hero.backgroundImage` 값을 그 파일명으로 바꾸면 됩니다.
- 사진 위에는 가독성을 위해 자동으로 어두운 틸 오버레이가 깔립니다.

## 시공 사례 Before/After (다음 단계에서 연결 예정)

- 예: `case-cafe-before.jpg`, `case-cafe-after.jpg` …
- 사진을 주시면 사례 카드의 회색 placeholder를 실제 사진으로 교체해 드립니다.
